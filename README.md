Descripción y Estrategia del ProyectoEste repositorio contiene la solución técnica al Examen Final de Automatización de Pruebas (TA_EX_7), cumpliendo con los requisitos de integración de Git, Maven, Integración Continua (CI) y Despliegue Continuo (CD), basados ​​en las Unidades I, II y III del material de estudio (ME_1 a ME_6).1.1. Objetivo principalEl objetivo es demostrar la capacidad de configurar un pipeline automatizado de software que asegure la calidad desde la etapa de commit hasta el despliegue en un ambiente de pruebas.1.2. Arquitectura del Pipeline de CI/CD (Actividades 2 y 3)Se utiliza GitHub Actions (o equivalente) para implementar el flujo de CI/CD bajo el modelo Pipeline as Code . El archivo de configuración principal es .github/workflows/ci_cd.yml.El pipeline se dispara automáticamente con cada empuje a la rama developy consta de cuatro etapas ( stages) secuenciales:Flujo CI/CD:#Etapa (Trabajo)Fundamento (ME)Descripción y Requisito (TA_EX_7)1.BuildME_3: Integración ContinuaCompilación del código fuente y validación de sintaxis.2.TestME_3, R_3Ejecución de las Pruebas Unitarias y de Integración. Si fallan, el oleoducto se detiene.3.Acceptance TestsME_5: Puerta de CDEjecución de las Pruebas de Aceptación/Funcionales (E2E). Funciona como una Puerta de Calidad antes del despliegue.4.Deploy to StagingME_5: Tuberías de DespliegueDespliegue del artefacto de software en el ambiente de pruebas ( Staging).Estrategia de RecuperaciónPara asegurar la rápida recuperación ante fallos en producción, se implementa el patrón Blue-Green Deployment (ME_6: Sección 3.1):Definición: El despliegue de la nueva versión se realiza en el entorno Green , manteniendo el entorno anterior (Blue) activo y recibiendo tráfico.Rollback: Si la versión Green presenta errores post-despliegue, la recuperación es instantánea y se logra simplemente re-enrutando el tráfico de vuelta al entorno Blue (versión anterior estable). Esta técnica minimiza el tiempo de inactividad y cumple con el requisito de implementar una estrategia de recuperación.5.
